# 全局 BP (Fearless Draft) 純行為預測架構規格書
### Pure Behavioral Draft Prediction: Conditioning on Identity, Context, and Algorithmic Hard Constraints

---

## 1. 核心定位與設計哲學

本系統專注於「**電競教練與選手選角決策模仿（Behavior Cloning）**」，定位為條件機率序列生成模型。四大核心原則：

1. **預測「會選什麼」，而非「怎麼選才能贏」**：
   - 不追求勝率最優解，不跑蒙地卡羅博弈樹（MCTS），不引入任何勝負回饋的價值網絡（Value Network）。
   - 輸贏是 30 分鐘局內對抗的結果，賽前 BP 本質上反映的是教練團的準備、選手的英雄池深度與賽區風格習慣。
2. **零人工標籤 (Zero Human Bias)**：
   - 徹底揚棄「打架隊」、「工具人」、「鬥士專精」等人工標籤，避免標籤滯後於版本與選手轉型。
   - 選手與隊伍風格全部由離散識別碼映射至高維連續向量（Embedding Latent Space），由模型自監督學習。
3. **零局內數據 (Zero In-Game Stats)**：
   - 完全排除 KDA、分均傷害、吃兵差等局內數值，只關注賽前客觀發生的行為與時空脈絡。
4. **演算法級硬性邊界 (Algorithmic Action Masking)**：
   - 深度學習負責「機率打分」，傳統集合運算負責「死守邊界」。
   - 全局 BP 前幾局用過的英雄在數學上機率恆等於 0，絕無任何違規幻覺。

```
┌────────────────────────────────────────────────────────┐

                           │ 輸出候選空間未歸一化得分 (Raw Logits)
                           ▼
┌────────────────────────────────────────────────────────┐
│        演算法動態硬約束層 (CSP Hard Action Masking)     │
│   • 英雄 ∈ Fearless 歷史已選集合   -> 遮蔽為負無窮大   │
│   • 英雄 ∈ 當局已 Ban 集合         -> 遮蔽為負無窮大   │

                           │
                           ▼ Softmax 歸一化
┌────────────────────────────────────────────────────────┐

│       (例：納兒 42%、藍寶 28%、卡桑帝 14% ...)         │
└────────────────────────────────────────────────────────┘
```

## 3. 輸入特徵模組化規範 (Input Specifications)

系統所有特徵皆為客觀、可查驗的數值或識別標識，不帶任何主觀打分：

| 模組分類 | 具體輸入項目 | 數學形式與功能 |
| :--- | :--- | :--- |
| **環境層 (Context)** | • 遊戲版本 (`patch`)<br/>• 賽區 (`region_id`)<br/>• 局數 (`game_number`, 1~5)<br/>• 陣營 (`side`: Blue/Red)<br/>• 當前選角步驟 (`step_idx`: 1~20) | 決定版本基準優先級、賽區 Meta 差異與全局局數消耗壓力。 |
| **約束層 (Constraints)** | • 全局已選名單 ($\mathcal{U}_{\text{fearless}}$)<br/>• 當局已 Ban 名單 ($\mathcal{B}_{\text{current}}$)<br/>• 當局已 Pick 名單 ($\mathcal{P}_{\text{current}}$) | 透過集合差集轉換為布林遮罩向量，約束可選空間。 |
| **實體層 (Identity Embedding)** | • 隊伍識別碼 (`team_id`)<br/>• 當前上場 10 位選手識別碼 (`player_id`)<br/>• 選手對應位置 (`role`) | 讓神經網絡透過反向傳播自適應學習個人偏好與戰術權威；天然支援輪換選手動態拼接。 |
| **純歷史行為層 (Pick History)** | • 該選手在近 $N$ 場實際選用英雄頻率向量（含時間衰減係數 $\lambda^t$） | 無局內勝負，僅依據客觀登場紀錄平滑體現選手近期角色池轉型。 |

## 4. 核心數學模型與演算法邊界

### 4.1 條件機率分佈建模
將第 $t$ 手選角預測視為在給定當前所有背景條件下的條件機率建模：
$$P(c_t \mid \mathcal{S}_t) = P(c_t \mid \text{Context}, \text{Roster}, \text{History}, \mathcal{P}_{1:t-1})$$
其中 $c_t$ 為候選英雄集合 $\mathcal{C}$ 中的任一英雄。

### 4.2 演算法級約束滿足 (CSP Action Masking)
為了達成傳統演算法 100% 合規的嚴謹度，神經網絡不參與規則有效性的判斷，而是由集合論公式進行硬性剪枝。定義合法動作指示向量 $M \in \{0, 1\}^{\vert\mathcal{C}\vert}$：
$$M(c) = \begin{cases} 1, & \text{if } c \notin (\mathcal{U}_{\text{fearless}} \cup \mathcal{B}_{\text{current}} \cup \mathcal{P}_{\text{current}}) \text{ 且 } \text{RoleValid}(c) \\ 0, & \text{otherwise} \end{cases}$$

神經輸出得分在進入機率歸一化前，透過遮罩投影強行修正：
$$\text{Logits}_{\text{masked}}(c) = \begin{cases} \text{Logits}_{\text{raw}}(c), & \text{if } M(c) = 1 \\ -\infty, & \text{if } M(c) = 0 \end{cases}$$

最終輸出合法機率分佈：
$$P(c) = \frac{\exp(\text{Logits}_{\text{masked}}(c))}{\sum_{c' \in \mathcal{C}} \exp(\text{Logits}_{\text{masked}}(c'))}$$

此機制保證非法或已被全局 BP 消耗的英雄，其輸出機率在數學上恆等於 $0$。

## 5. 模型訓練與評估規範

### 5.1 訓練樣本構建 (Data Formulation)
- **資料來源**：全量職業聯賽歷史對局（不區分勝負，勝隊與敗隊之選角皆視為合法行為樣本）。
- **樣本切片**：每場對局依照 BP 順序切分為 20 個獨立決策樣本：
  - **輸入狀態 ($\mathcal{S}_t$)**：前 $t-1$ 步選禁紀錄、全局已用名單、雙方出場選手 ID、隊伍 ID、賽區與版本。
  - **真值標籤 ($y_t$)**：真實教練團在該步驟鎖定的英雄 ID。

### 5.2 損失函數 (Loss Function)
採用標準多分類交叉熵損失（Cross-Entropy Loss）：
$$\mathcal{L} = -\sum_{c \in \mathcal{C}} y(c) \log P(c)$$
在遮罩機制下，被 Mask 掉的英雄梯度完全為 0，反向傳播僅在當前合規的候選英雄之間進行權重微調。

### 5.3 評估指標 (Evaluation Metrics)
- **Top-1 Accuracy**：首選英雄完全命中率。
- **Top-3 / Top-5 Accuracy**：由於真實教練決策通常存在 2 至 3 個同等優先級的備選方案，Top-3 與 Top-5 命中率是衡量模型實戰參考價值與商用可用性的核心指標（基準線預期可達 80%~90%）。

## 6. 技術路徑效益總結

| 維度 | 傳統勝率推演方案（RL / 價值網絡 / MCTS） | 本方案（純行為預測 + 演算法硬約束） |
| :--- | :--- | :--- |
| **系統目標** | 尋求理論勝率最優解（How to win） | 精準預測對手與隊伍真實動向（What they actually do） |
| **數據乾淨度** | 依賴勝負結果，受局內爆冷與選手狀態雜訊干擾 | 僅依賴真實登場紀錄，客觀無雜訊 |
| **運算延遲** | 需多步前瞻樹搜尋，推理耗時長 | 單次前向傳遞，毫秒級低延遲響應 |
| **邊界精確度** | 需依賴罰分函數探索收斂 | 輸出層演算法遮罩硬保證，100% 合規無幻覺 |
